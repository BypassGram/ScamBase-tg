# BypassGram ScamBase-tg

Официальная база данных мошенников, вредоносных каналов и опасных юзернеймов для Telegram-клиента BypassGram.

## Источник базы
- JSON: `https://raw.githubusercontent.com/BypassGram/ScamBase-tg/main/scammers.json`
- TXT: `https://raw.githubusercontent.com/BypassGram/ScamBase-tg/main/scammers.txt`

## Содержимое
База содержит Telegram ID и юзернеймы распространителей вредоносного ПО, краш-стикеров и мошенников.

## Подать жалобу
Для добавления мошенника в базу обратитесь в канал: [@notoscam_bpgram](https://t.me/notoscam_bpgram).
